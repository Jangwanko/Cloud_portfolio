사용자 주문 흐름

결제 완료, 주문 완료 응답만 사용자에게 보여준다.

결제 완료와 주문 완료 이후의 저장, 분류, 알림, DLQ 처리는 내부 이벤트 파이프라인에서 이어진다. 실제 Worker persistence 증거를 보기 위해 전송 전 데모 주문 stream을 준비한다.
